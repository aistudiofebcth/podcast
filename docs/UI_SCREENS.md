# UI Screen Design — Reference

Reference designs for the **FEBC Podcast Design System**. These are the source
screens the components were built to compose.

> **Why links, not images?** This build environment blocks downloading Figma
> asset files (`www.figma.com` is egress-restricted), so each screen links to
> its exact Figma node instead of shipping a static export. Open a link — or
> hand it to **Claude Code with the Figma MCP** — to reference the real design
> while developing. Screens marked **✎** are reproduced 1:1 in `src/screens/`.

**Full board:** [↪︎ UI Screens (all 37) in Figma](https://www.figma.com/design/yDptxi61nJ5FgxfOPNi7mR/ZenTune-Music-Streaming-Mobile-UI-Kit?node-id=3-88&m=dev)

## Note on icons

The Figma **Icons** page (`node-id=3-90`) holds a large line-icon library
(Hugeicons-style). Because the environment can't download Figma SVGs, the icon
set in `src/components/icons/` is authored in-house to match that style (stroke
line icons, ~1.8px, `currentColor`). Swap in the exact SVGs — or an equivalent
open-source set (e.g. Hugeicons via npm) — when running where Figma export is
available.
